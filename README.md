# `aenriii/dotnix`

my personal nix config files for desktops and users alike.

## what's here

### host `deaddove`

my main pc, pyria-hardened and running vaultwarden as a background service thru
tailscale.

### host `villa`

my main laptop, a thinkpad x1 carbon 6th gen with an i7 and 16gb of ram. uses
`deaddove` as a nix build server whenever possible.

### user `aenri`

a simple cli-only subset of my configurations set up as a home-manager config.

### user `aenri@gui`

graphical desktop access but no nixos? worry not! for i have all of my config
files set up with this one, and a bunch of applications.
